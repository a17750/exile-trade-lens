# 分类响应语料库

该目录保存按 `type_filters.category` 采集并脱敏的官方交易站第一页响应。

- `category-pages.en.json`：国际服公开 API 响应。
- `category-pages.zh-TW.json`：台服已登录页面捕获的官方繁中响应。
- 每个分类保存页面首批渲染的 10 件物品，避免将回归语料变成全站爬取。
- `listing`、卖家账号、价格、原始物品 ID、Cookie 与访问令牌不会写入语料库。
- 仅保存结果 ID 的单向 SHA-256 摘要，用于同一件物品的英繁响应对齐。
- 采集按分类原子落盘；中断后重新运行会跳过已完成分类。

语料库只用于构建结构签名、英繁对齐和回归测试，不直接作为无领域的全文翻译词典。
