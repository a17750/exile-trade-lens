# 权限说明

当前扩展版本：`0.5.6`。

## 已申请权限

### `storage`

用途：

- 保存是否启用汉化、显示模式和远程词库地址。
- 缓存经过校验的远程词库。
- 保存漏译记录和本地人工修正。
- 保存最后一次更新状态。

数据默认仅保存在浏览器中。当前版本不上传漏译或用户数据。

### `alarms`

用途：

- 每 12 小时唤醒 Manifest V3 Service Worker 检查词库更新。

不使用永久后台页面，也不持续轮询。

## 主机权限

### `https://www.pathofexile.com/*`

### `https://pathofexile.com/*`

用途：

- 只在 `/trade2` 页面加载本地内容脚本。
- 读取并修改该页面已经获取的交易数据，用于翻译和漏译检测。

不读取 Cookie，不额外批量调用搜索接口，不自动发送私聊。

台服官方交易接口只在维护者的构建脚本或 GitHub Actions 中读取，不由已安装扩展直接请求，因此无需增加 `https://pathofexile.tw/*` 主机权限，也不需要台服账号。

### `https://raw.githubusercontent.com/*`

### `https://cdn.jsdelivr.net/*`

用途：

- 下载用户配置的远程词库清单和 JSON 数据。
- 只接受 HTTPS，并验证 SHA-256。

远程数据不能包含可执行代码。

## 不需要新增权限的自检功能

下面这些使用现有 `storage` 和 `action` 能力，不需要额外权限：

- 检测缺失翻译。
- 在内存中识别输入事件派生区域；不读取或保存输入框的值。
- 本地保存漏译记录。
- 插件图标显示数字角标。
- 打开扩展自身的漏译管理页。
- 手工保存本地修正。
- 导出 JSON；管理页使用浏览器普通 Blob 下载，不调用 `chrome.downloads`。

## 当前没有申请的敏感权限

- `cookies`：不读取登录 Cookie 或 POESESSID。
- `history`：不读取浏览记录。
- `tabs`：不读取标签页标题、URL 或历史；创建扩展管理页不需要该权限。
- `webRequest`：不使用后台网络监听权限。
- `declarativeNetRequest`：不修改浏览器级请求规则。
- `notifications`：不发送系统通知，使用图标角标。
- `downloads`：不管理用户下载历史。
- `clipboardRead` / `clipboardWrite`：不读取剪贴板。
- `nativeMessaging`：不连接本机程序。
- `<all_urls>`：不访问所有网站。

## 未来功能可能需要的权限

只有真正实现以下功能时才考虑新增，并应当单独讨论：

| 功能 | 可能需要的权限 | 当前建议 |
|---|---|---|
| 系统级漏译通知 | `notifications` | 暂不需要，角标足够 |
| 一键读取复制的装备 | `clipboardRead` | 建议用户主动触发时再申请 |
| 与桌面查价器通信 | `nativeMessaging` 或固定 localhost 主机权限 | 做成明确可选功能 |
| 导入本地文件 | 通常可用文件选择器，无需额外权限 | 不申请文件系统权限 |
| 匿名上传漏译 | 固定上报域名的 host permission | 必须先做隐私披露和用户同意 |

## 商店发布前还需要的非权限事项

- 提供可公开访问的隐私政策。
- 在商店数据披露中说明网页内容仅本地处理。
- 明确声明不收集账号、私聊、Cookie 和搜索历史。
- 提供 GGG 非官方产品声明。
- 添加扩展图标和商店截图。
- 后续若上架商店，评估是否取消自定义更新地址，只保留项目固定 GitHub/CDN 地址。
