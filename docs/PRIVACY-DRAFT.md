# 隐私说明草案

流亡译镜仅在 Path of Exile 2 官方交易站页面运行，用于在用户浏览器中本地翻译页面内容并检测缺失翻译。

扩展不会收集、保存或上传用户的 Path of Exile 登录凭据、Cookie、POESESSID、账号名称、卖家名称、私聊内容、搜索历史或交易价格。

漏译自检只在本地保存标准物品/词缀 ID、英文标准文本、数据版本和出现次数。当前版本不会把漏译报告发送给开发者或任何第三方。用户主动点击“导出报告”时，扩展会在本地生成 JSON 文件。

扩展会从用户配置的 GitHub Raw 或 jsDelivr 地址下载翻译词库。请求只用于获取公开的版本清单和 JSON 数据，不附带 POE 登录信息。下载的数据经过 SHA-256 校验后保存在浏览器本地。

所有本地数据均可通过移除扩展或清理扩展存储删除。
